# Stage 0 — Organização

## Objetivo

Preparar o repositório para o desenvolvimento do addon.

## Incluído

- documentação;
- roadmap;
- arquitetura;
- estrutura de diretórios;
- áreas reservadas para Behavior Pack e Resource Pack;
- área de configuração;
- testes e ferramentas.

## Não incluído

- tsunami funcional;
- física;
- correntes;
- destruição;
- detritos.

## Conclusão

A Stage 0 está pronta quando o repositório estiver organizado para receber a Stage 1.
