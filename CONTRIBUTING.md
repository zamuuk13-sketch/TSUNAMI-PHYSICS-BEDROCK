# 🤝 Contribuindo

O projeto é desenvolvido por etapas.

1. Não misture sistemas futuros sem necessidade.
2. Preserve a etapa atual.
3. Isole experimentos.
4. Documente decisões importantes.
5. Priorize desempenho.
6. Evite dependências externas desnecessárias.

Cada etapa deverá possuir testes quando sua implementação começar.
