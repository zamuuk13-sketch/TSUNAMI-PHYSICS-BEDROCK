# Changelog

## 0.0.0 — Stage 0

- Repositório organizado.
- README criado.
- Roadmap das etapas 0–20 criado.
- Arquitetura inicial documentada.
- Guia de contribuição criado.
- Estrutura de diretórios preparada.

## 0.2.0 — Stage 2

- Primeiro tsunami funcional implementado.
- Comando `!tsunami` adicionado.
- Comando `!tsunami stop` adicionado.
- Frente de onda progressiva com largura e altura configuráveis.
- Primeira inundação baseada em blocos de água.
- Partículas e áudio básicos da onda.
- Stage 2 aguardando teste real no Bedrock.

## 0.3.0 — Stage 3

- Inundação passou a consultar o terreno.
- Crista da onda acompanha alturas diferentes do mapa.
- Água não substitui blocos sólidos comuns.
- Inundação se espalha progressivamente para áreas vizinhas e baixas.
- Limites de processamento adicionados para controlar custo por atualização.
- Stage 2 marcada como concluída após teste informado pelo usuário.
- Stage 3 aguardando teste real no Bedrock.

## 0.4.0 — Stage 4

- Física básica do jogador na água adicionada.
- Arrasto e corrente aplicados progressivamente.
- Submersão detectada.
- Flutuação vertical básica adicionada.
- Stage 3 marcada como concluída após teste informado pelo usuário.
- Stage 4 aguardando teste real no Bedrock.
